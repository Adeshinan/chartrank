# ChartRank

**Propose et explique le bon graphique selon vos données et votre intention.**

Donnez à ChartRank une ou deux colonnes et une intention. Il propose 3 à 5
graphiques dessinés sur vos données, marque la recommandation ★, explique chacun
avec des chiffres calculés sur vos données et fournit l'image ou un script Python
autonome pour le refaire. Déterministe, local, sans IA.
