# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment and
discriminatory behaviour are not tolerated.

To report unacceptable behaviour, contact the maintainer through their
[GitHub profile](https://github.com/Adeshinan). Reports will be handled
confidentially.
